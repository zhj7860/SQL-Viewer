## 1. 启动

双击 `SqlStructViewer.exe`。窗口打开时是空的，状态栏显示：

```
就绪。可拖放 .sql 文件到窗口，或在「路径」框粘贴路径后回车。
```

不需要管理员权限，不需要安装，不写注册表，不联网。

---

## 2. 五种打开方式

### 2.1 粘贴路径（最快）

工具栏有一个 `路径:` 输入框：

```
路径: [ D:\project\ddl                                    ] [打开路径]
```

1. 在资源管理器里 `Ctrl+C` 复制文件或文件夹路径（或在地址栏复制）
2. 点进「路径」框，`Ctrl+V`
3. 按 **回车**

规则：

| 粘贴内容 | 行为 |
|---|---|
| 文件夹路径 | 收集该文件夹下的 `*.sql`、`*.ddl`、`*.txt`，按文件名排序载入 |
| 单个文件路径 | 直接载入（不限扩展名） |
| 多个路径 | 用 `;` 或**换行**分隔，逐个处理 |
| 含空格的路径 | 直接粘即可（会先整体尝试）；也可以写成 `"D:\my folder\a.sql"` |

> 只想定位到输入框？按 `Ctrl+Shift+O`（菜单 `文件 → 从路径打开…`），会自动聚焦并全选。

### 2.2 拖放

把文件**或文件夹**从资源管理器拖到窗口任意位置。文件夹会被递归收集其中的 `*.sql / *.ddl / *.txt`（仅当前层，不递归子目录）。

### 2.3 打开文件

`Ctrl+O` 或工具栏 `[打开文件]`。文件对话框支持多选，`Ctrl+A` 全选整个目录。

### 2.4 打开文件夹

`Ctrl+Shift+D` 或工具栏 `[打开文件夹]`。

打开的是 Windows 现代文件夹选择器（Vista 起的 Common Item Dialog）：

- 顶部有**面包屑地址栏** —— 点进去可以 `Ctrl+V` 直接粘贴路径并回车跳转
- 支持**多选文件夹**（`Ctrl` 或 `Shift` 点选）
- 选完后第一个路径会回填到工具栏「路径」框

> 如果系统上没有这个现代对话框（极老系统），程序会自动退回旧式的树形文件夹对话框。

### 2.5 命令行 / 文件关联

```cmd
SqlStructViewer.exe "D:\project\ddl"
SqlStructViewer.exe a.sql b.sql "D:\more-ddl"
```

参数可以是文件或文件夹，可以混用、可以多个。因此也可以把 `.sql` 关联到本程序：双击 `.sql` 文件即用它打开。

## 3. 界面说明

### 3.1 左侧：表清单

| 列 | 含义 | 来源 |
|---|---|---|
| 表名 | 表名 | `CREATE TABLE <name>` |
| 字段 | 字段个数 | 解析出的列数量 |
| 主键 | 主键列，逗号分隔；复合主键全部列出 | `PRIMARY KEY (...)` |
| 来源 | DDL 头部注释里的 `Source` | `-- Source : CRM` |

单行选中。选中后右侧立即刷新。

### 3.2 右侧：字段网格

顶部灰底区域显示：`表名　[来源]　N 字段`，第二行是表说明（来自 DDL 头部 `-- Description`）。

| 列 | 含义 |
|---|---|
| `#` | 序号（按 DDL 中出现顺序，不改动） |
| 字段名 | 列名（统一大写显示） |
| 类型 | 原样保留，如 `NUMBER(22)`、`VARCHAR2(256)`、`DATE`、`TIMESTAMP`、`CLOB` |
| 空 | `Y` = 可为空，`N` = `NOT NULL` |
| PK | 该列是主键时显示 `PK` |
| 注释 | 字段上方 `--` 注释行的内容（多行会拼成一行） |

### 3.3 状态栏

```
已载入 110 张表 / 4040 个字段   D:\project\ddl
```

如果有的文件读不出来，会追加 `（N 个文件读取失败）`。

## 4. 过滤表

工具栏 `过滤:` 框输入子串，左侧表清单**即时**筛选（不区分大小写），右侧工具条右侧显示 `表 <命中> / <总数>　字段 <总数>`。

清空输入框即恢复全部。注意：过滤只影响左侧清单显示，不影响已载入的数据。

## 5. 把字段导出到 Excel / Markdown

1. 左侧选中目标表
2. 点进右侧字段网格，`Ctrl+A` 全选，`Ctrl+C` 复制

得到的是 **TSV**（制表符分隔），列顺序为：`# / 字段名 / 类型 / 空 / PK / 注释`。

- 粘进 Excel / WPS：自动分列
- 只要部分行：按住 `Ctrl` 点选，再 `Ctrl+C`
- 右键菜单也有「复制选中行 / 复制全部行」

## 6. 命令行与诊断模式

```cmd
:: 正常打开
SqlStructViewer.exe <路径> [<路径> ...]

:: 本次运行强制界面语言（zh | en）
SqlStructViewer.exe --lang en <路径> [<路径> ...]

:: 诊断模式：不弹窗，把解析结果写成文本
SqlStructViewer.exe --dump <输入.sql> <输出.txt>
```

`--dump` 适合：

- 排查「为什么这张表没显示出来」
- 批处理比对，例如校验一批 DDL 是否被正确解析

输出格式：

```
TABLE INF_SUBSCRIBER  [CRM]  cols=73  pk=SUBS_ID
  desc: Subscriber basic information.
      1  SUBS_ID                   NUMBER(22)      NOT NULL PK 
      2  SUBS_NAME                 VARCHAR2(256)               
      3  PROD_INST_ID              NUMBER(22)                  
```

批量跑一遍：

```cmd
mkdir out
for %f in (ddl\*.sql) do SqlStructViewer.exe --dump "%f" "out\%~nf.txt"
```

## 7. 解析规则细节

### 7.1 表怎么被切分

按 `CREATE TABLE` 逐条切分，靠括号配平找到语句结尾。同一个文件里有多张表会被全部识别，左侧清单出现多行。

### 7.2 注释怎么归属

DDL 里字段上方的 `--` 注释行会归属到**紧随其后的那个字段**：

```sql
CREATE TABLE T (
  -- 用户 ID。
  -- [PK]
  ID     NUMBER(22) NOT NULL,
  -- 用户名称。
  NAME   VARCHAR2(256)
);
```

`-- [PK]` 这类标记行会被识别为主键标记，不会混进注释文本。分隔装饰行（`-- ====`、`-- ----`）自动忽略。

### 7.3 主键怎么来

两个来源，合并处理：

1. 表级约束：`CONSTRAINT PK_T PRIMARY KEY (A, B)`
2. 列内联：`A NUMBER(22) PRIMARY KEY`
3. 注释标记：`-- [PK]`

复合主键会全部列出，例如 `pk=GROUP_ID+BE_ID+HIS_DATE`。

> 如果源规格文档里的主键和 DDL 内的主键标记冲突，**以 DDL 为准**。

### 7.4 类型怎么写

类型原样保留并统一大写，不做映射、不做校验。`NUMBER(20,6)` 这种带逗号的精度不会被误当作两个字段。

### 7.5 编码

先按 UTF-8 严格解码；遇到非法字节序列则回退 GBK（cp936）；仍失败则用系统默认编码。BOM 自动去除。

### 7.6 会忽略什么

- `INSERT` / `SELECT` / `COMMENT ON TABLE` 等非建表语句
- 表级 `UNIQUE` / `FOREIGN KEY` / `CHECK` / `INDEX` / `KEY` 约束行
- 单独的 `CREATE VIEW` / `CREATE INDEX`
- 解析不出「列名 + 类型」的行会被安静跳过

## 8. 故障排查

| 现象 | 原因 / 处理 |
|---|---|
| 左侧空，状态栏显示 0 张表 | 文件里没有可识别的 `CREATE TABLE`。用 `--dump` 看解析结果；确认不是 `CREATE TABLE ... AS SELECT` 之类的写法 |
| 状态栏显示「N 个文件读取失败」 | 文件被占用、无权限或编码异常。关掉占用程序后重试 |
| 提示「路径不存在或其中没有可读文件」 | 粘贴的路径有误，或文件夹里没有 `.sql/.ddl/.txt` |
| 粘贴路径后回车没反应 | 确认光标在「路径」框内再按回车；或点 `[打开路径]` 按钮 |
| 首次运行被 SmartScreen 拦截 | 「更多信息」→「仍要运行」。未签名的自编译程序都会这样 |
| 表结构显示不全 | 该 DDL 使用了本工具未覆盖的方言写法，见 §7.6 |

## 9. 切换语言

界面提供**中文与 English**两种语言，切换立即生效，无需重启。

**首次运行**。跟随 Windows 显示语言：中文系统启动为中文，其他系统启动为英文。

**手动切换**。菜单 **语言 → 中文 / English**。整个窗口立即改名，并记住选择供下次使用。

**记录位置**。

```
%APPDATA%\SqlStructViewer\lang.txt      （内容：zh 或 en）
```

删掉该文件即恢复自动判断。

**单次覆盖**。加 `--lang` 参数：

```cmd
SqlStructViewer.exe --lang en D:\ddl
SqlStructViewer.exe --lang zh D:\ddl
```

`--lang` 只影响**本次运行**，不会覆写上面的偏好文件。

**万一进错了语言**，看顶部菜单栏：第三个就是语言菜单（`Language` / `语言`），
里面两项始终用各自的文字写成 `中文` 和 `English`，总能找回来。
